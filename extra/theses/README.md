## 📊 Summary of Technical Achievements in Report

1. **Dataset:** 184,029 authentic Indian shipment records across 8 transportation sectors.
2. **19-Model Machine Learning Tournament:** Voting Regressor champion with $R^2 = 0.9624$, RMSE = 2.873h, MAE = 1.290h.
3. **25km Distance Stratification:** Bagging Regressor wins hyperlocal ($\le 25$ km, MAE 4.8 min), KNN wins interstate corridor routing (97.7% accuracy).
4. **On-Device Small Language Model (SLM):** ModernBERT-421M fine-tuned to 99.35% routing accuracy on NVIDIA RTX 3050 GPU (CUDA 12.4).
5. **Hardware Crash Resolution:** Resolved Windows CUDA fast-fail (`0xC0000409`) memory access violations.
6. **Explainability & Green Telematics:** Game-theoretic Tree SHAP factor attributions and GLEC/DEFRA freight carbon emission auditing.
