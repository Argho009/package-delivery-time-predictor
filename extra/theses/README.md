## 📊 Technical Achievements Documented in Report

1. **Inland India Logistics Dataset:** 184,029 authentic shipment records across 8 critical sectors (Delhivery, Amazon India, Bangalore traffic, Indian Railways freight, IMD monsoon, and festival surges).
2. **19-Model Machine Learning Tournament:** Voting Regressor champion ($R^2 = 0.9624$, $\text{RMSE} = 2.873\text{h}$, $\text{MAE} = 1.290\text{h}$).
3. **25km Hyperlocal Distance Discretization:** Bagging Regressor wins short-haul deliveries ($\le 25\text{ km}$, $\text{MAE} = 4.8\text{ min}$), KNN wins interstate corridor routing (97.7% accuracy).
4. **On-Device Small Language Model (SLM):** ModernBERT-421M (`convaiinnovations/laya-typed-decisions`) fine-tuned to **99.35% routing accuracy** on local NVIDIA RTX 3050 GPU (CUDA 12.4).
5. **Hardware Crash Resolution:** Resolved Windows CUDA fast-fail (`0xC0000409`) memory access violations in multi-threaded Werkzeug environments.
6. **Explainability & Green Telematics:** Game-theoretic Tree SHAP factor attributions and GLEC/DEFRA freight carbon emission auditing.
