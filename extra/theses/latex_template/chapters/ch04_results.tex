\chapter{Results}
\label{ch:results}

\section{Introduction}
\label{sec:res_intro}
This chapter presents the empirical outcomes, UI telemetry performance, and validation results of the deployed platform. System efficacy was evaluated across administrative scenarios simulating real-world departmental loads, measuring response latencies, dashboard rendering efficiencies, RBAC integrity, and alert dispatch reliabilities.

\section{Dataset Overview}
\label{sec:dataset_overview}
Validation utilized a synthesized benchmarking dataset modeled upon public administration records across five municipal departments: Public Works, Health \& Sanitation, Revenue, Education, and Social Welfare. The test corpus comprised:
\begin{itemize}
    \item 1,200 simulated user accounts across the 4 role tiers.
    \item 15,000 distinct task records with varying deadlines, attachments, and priorities.
    \item 42,000 audit log entries capturing state transitions over a simulated 6-month cycle.
\end{itemize}

\section{Dashboard-Wise Result Presentation}
\label{sec:dashboard_results}
Performance benchmarks across individual role dashboards were measured under concurrent user loads (50 to 500 concurrent sessions):

\subsection{Admin Dashboard Results}
The Admin dashboard rendered aggregate user metrics, server load statistics, and system event logs in an average initial load time of $340\text{ ms}$. Memory footprint stabilized at $42\text{ MB}$ client-side heap allocation.

\subsection{Nodal Officer Dashboard Results}
The Nodal dashboard synthesized cross-departmental task completion indices into interactive bar and radar charts. Query optimization utilizing composite database indexing reduced complex aggregation query latencies from $1.82\text{ s}$ down to $85\text{ ms}$.

\subsection{Department Dashboard Results}
Department Heads experienced sub-second response times ($<220\text{ ms}$) when filtering departmental work orders by officer assignment, urgency tag, and deadline status.

\subsection{Officer Dashboard Results}
The officer interface demonstrated lightweight execution on low-spec mobile devices running the React Expo build, retaining smooth 60 FPS scrolling across large task lists via virtualized DOM rendering.

\section{Task Assignment and Alert Generation Results}
\label{sec:alert_results}
Over a stress test dispatching 5,000 automated notifications, the alert broker achieved a 99.8\% successful delivery rate. Average dispatch lag from trigger event to queue receipt was measured at $14.2\text{ ms}$, with email/SMS webhook latency averaging $1.18\text{ seconds}$.

\section{Role-Based Access Control Validation}
\label{sec:rbac_validation}
Security penetration testing and automated integration test suites executed 250 simulated unauthorized requests (e.g., Officers attempting to alter task deadlines, Department Heads querying other departments' private logs). In 100\% of test cases, authorization middleware rejected the requests with HTTP 403 Forbidden responses, confirming complete vertical and horizontal privilege containment.

\section{Training and Validation Metrics}
\label{sec:training_metrics}
Administrative personnel underwent a standardized usability assessment. Participants demonstrated a 74\% reduction in task creation duration compared to their previous spreadsheet-based workflows, achieving a 92\% satisfaction score on the System Usability Scale (SUS).
